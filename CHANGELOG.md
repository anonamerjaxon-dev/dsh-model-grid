# Changelog

## 1.0.0 — 2026-10-22

- Initial public release.
- Turns the composer model picker into a responsive card grid, grouped by provider.
- Supports the stock `dsh-client-ui-model-selection` dropdown and the `dsh-peakrate` model menu.
- Configurable width, card width, gap, height cap, and countdown visibility.
- Host-only delivery through `webserver/index-inject`; no client bundle rebuild.
- Unit tests and CI.
